Python API
==========

:py:class:`fvqual.engine.Library` loads the shared library.
:py:class:`fvqual.engine.Mesh` and :py:class:`fvqual.engine.Simulation`
manage native mesh and simulation handles. See :doc:`design` for the binding
design, and the module index for coupling, replay and uncertainty calculations.
